## 지도에 접속하기

플래닛어스 지도는 인게임에서 `/map` 명령어로 주소를 받거나 [웹 지도에 직접 접속](https://planetearth.kr/map)해 볼 수 있습니다.

마우스 스크롤로 지도를 확대·축소할 수 있습니다. 각 버튼으로 지도의 여러 기능을 사용할 수 있습니다. 지도에는 유저들이 만든 마을, 특산품, 점령전(KOTH), 접속 중인 플레이어의 현재 위치가 표시됩니다.

## 기능 설명

### 좌표 보기

지도에서 특정 위치의 좌표를 확인할 수 있습니다.

<img src="/img/docs/getting-started/map/map-coordinates-01.png" className="dynmap-screenshot" alt="지도 좌측 하단의 위치 좌표와 링크 버튼" width="300" height="300" loading="lazy" />

지도 좌측 하단에 좌표가 표시됩니다. 표시되는 좌표는 마우스 커서 위치에 따라 바뀝니다.

좌표 왼쪽 버튼을 누르면 해당 좌표를 중심으로 하는 웹 지도 링크가 클립보드에 복사됩니다.

### 원하는 항목만 표시하기

지도에서 원하는 항목만 표시하거나 숨길 수 있습니다.

<img src="/img/docs/getting-started/map/layer-button-01.png" className="dynmap-screenshot" alt="노란 테두리로 강조한 레이어 버튼" width="300" height="300" loading="lazy" />

지도 좌측 상단에서 위와 같은 버튼을 클릭하세요.

<img src="/img/docs/getting-started/map/layer-checkboxes-01.png" className="dynmap-screenshot" alt="Markers, 특산품, Towny 등 항목별 체크박스" width="300" height="300" loading="lazy" />

버튼을 누르면 항목마다 체크박스가 표시됩니다. 체크박스를 켜고 꺼서 원하는 항목만 볼 수 있습니다.

### 지도 타입 바꾸기

현재 보고 있는 지도를 다른 타입으로 바꿀 수 있습니다.

<img src="/img/docs/getting-started/map/map-menu-buttons-01.png" className="dynmap-screenshot" alt="우측 상단 버튼 중 가장 왼쪽 지도 모양 버튼" width="300" height="300" loading="lazy" />

지도 우측 상단 버튼 중 가장 왼쪽 버튼을 클릭하세요.

<img src="/img/docs/getting-started/map/map-type-selection-01.png" className="dynmap-screenshot" alt="world와 moon의 맵 타입 선택 목록" width="300" height="300" loading="lazy" /><img src="/img/docs/getting-started/map/3d-map-preview-01.webp" className="dynmap-screenshot-wide" alt="surface 타입으로 본 3D 지형" width="1000" height="563" loading="lazy" />

버튼을 누르면 다른 타입의 지도를 선택할 수 있습니다. 예를 들어 `world`의 `surface` 타입을 선택하면 지구맵을 3D로 볼 수 있습니다.

### 마커 보기

특정 마을, 국가, 특산품, 전쟁 위치 등을 찾을 수 있습니다.

<img src="/img/docs/getting-started/map/map-menu-buttons-01.png" className="dynmap-screenshot" alt="우측 상단 버튼 중 가운데 위치 핀 모양 버튼" width="300" height="300" loading="lazy" />

지도 우측 상단 버튼 중 가운데 버튼을 클릭하세요.

<img src="/img/docs/getting-started/map/marker-categories-01.png" className="dynmap-screenshot" alt="Towny, 특산품, TownyKOTH 등 마커 카테고리 목록" width="500" height="500" loading="lazy" />

버튼을 누르면 카테고리 목록이 표시됩니다.

<img src="/img/docs/getting-started/map/marker-detail-list-01.png" className="dynmap-screenshot" alt="특산품 카테고리의 마커 검색 칸과 좌표 목록" width="500" height="500" loading="lazy" />

원하는 카테고리를 누르면 해당 항목이 표시됩니다. 각 항목의 좌표를 확인할 수 있고, 항목을 클릭하면 지도가 해당 위치로 이동합니다. 상단 검색 칸에서 이름으로 검색할 수도 있습니다.

### 플레이어 보기

현재 접속 중인 플레이어를 볼 수 있습니다.

<img src="/img/docs/getting-started/map/map-menu-buttons-01.png" className="dynmap-screenshot" alt="우측 상단 버튼 중 가장 오른쪽 사람 모양 버튼" width="300" height="300" loading="lazy" />

지도 우측 상단 버튼 중 가장 오른쪽 버튼을 클릭하세요.

<img src="/img/docs/getting-started/map/online-player-list-01.png" className="dynmap-screenshot" alt="플레이어 검색 칸과 접속자 목록" width="500" height="500" loading="lazy" />

버튼을 누르면 현재 접속 중인 플레이어가 표시됩니다. 플레이어를 클릭하면 지도가 해당 위치로 이동합니다. 상단 검색 칸에서 이름으로 검색할 수도 있습니다.

회색으로 표시된 플레이어는 현재 위치를 알 수 없는 플레이어입니다. 이런 플레이어는 스폰에 있을 가능성이 높습니다.

## 후원자 혜택

Pro 랭크 보유자는 자기 국가의 색을 바꿀 수 있습니다.

`/n set mapcolor [색깔]` 명령어로 변경합니다. 국왕만 사용할 수 있습니다.

자세한 내용은 [후원](/docs/shop) 문서를 참고하세요.
